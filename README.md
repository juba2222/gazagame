# هل ستنجو؟ / Will You Survive?

محاكاة تجربة مدني غزي خلال الحرب — A simulation of a Gazan civilian's experience during the war.

## وصف المشروع (Project Description)
هذا المشروع هو تجربة تفاعلية مبنية على أحداث حقيقية وقعت في قطاع غزة بين أكتوبر 2023 ويناير 2025. يهدف المشروع إلى وضع اللاعب في قلب المعاناة اليومية والقرارات الصعبة التي يواجهها المدنيون للبقاء على قيد الحياة.

## التقنيات المستخدمة (Technologies)
*   **Phaser 3**: محرك الألعاب المستخدم للرسوميات والمؤثرات البصرية وإدارة المشاهد.
*   **JavaScript (ES6+)**: للتحكم في منطق اللعبة والأنظمة الحيوية.
*   **HTML5/CSS3**: لبناء واجهة المستخدم (UI) ودعم النصوص العربية بشكل متجاوب.

## كيفية التشغيل (How to Run)
المشروع عبارة عن تطبيق ويب ثابت (Static Web App). لتشغيله بشكل صحيح وتجنب مشاكل المتصفح مع ملفات الـ Modules، يفضل استخدامه عبر خادم محلي:

### 1. باستخدام VS Code
*   قم بتثبيت إضافة **Live Server**.
*   انقر بزر الفأرة الأيمن على ملف `index.html` واختر **Open with Live Server**.

### 2. باستخدام Python
إذا كان لديك Python مثبتاً، قم بتشغيل الأمر التالي في مجلد المشروع:
```bash
python -m http.server 8000
```
ثم افتح الرابط `http://localhost:8000` في متصفحك.

### 3. باستخدام Node.js
```bash
npx serve .
```

## هيكلية الكود (Code Structure)
*   `js/main.js`: نقطة الانطلاق وإعدادات محرك Phaser.
*   `js/scenes/`: تحتوي على المشاهد المختلفة (إعداد، لعب، استشهاد، نهاية).
*   `js/events.js`: أرشيف الأحداث التاريخية والمراحل الزمنية.
*   `js/family.js`: نظام إدارة أفراد العائلة وحالاتهم الصحية.
*   `js/resources.js`: نظام إدارة الموارد (طعام، ماء، مال، دواء).

## ملاحظة (Note)
جميع البيانات والإحصائيات الواردة في اللعبة مستمدة من تقارير منظمات دولية مثل الأمم المتحدة (UN OCHA)، منظمة الصحة العالمية (WHO)، وبرنامج الأغذية العالمي (WFP).
